# Liquid Glass Launcher

Starter project for a customizable Android home-screen launcher built with Kotlin and Jetpack Compose.

## Current prototype
- Android HOME/launcher intent
- Home screen with liquid-glass-inspired translucent panels
- Clock and date
- App drawer with search
- Launch installed apps
- Basic glass-opacity control

## Build
1. Install Android Studio with Android SDK 36 and JDK 17.
2. Open this folder in Android Studio.
3. Allow Gradle sync.
4. Build > Build Bundle(s) / APK(s) > Build APK(s).
5. Install the debug APK on your Android phone.
6. Press Home and choose **Liquid Glass** as the Home app. Select Always if you want it as default.

## Notes
This is a source prototype, not a prebuilt APK. The weather card is decorative in this first build; live weather, persistent preferences, real swipe gestures, icon theming, wallpaper picker, backup and accessibility refinements are planned for later iterations.
